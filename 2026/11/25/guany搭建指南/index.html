Cloudflare + 域名实现个人自建节点

原作者：wuhongbo
原文：个人搭建节点（Cloudflare + 免费域名）
来源：科技源代码

核心亮点：永久免费、无需服务器、0 代码、10 分钟部署、自动优选 IP、4K 秒开、解锁流媒体、晚高峰可达 18w kb/s。

1. 项目优势

  • 解决痛点：机场跑路、节点污染、网速卡顿。
  • 网络优化：Cloudflare 自动优选 IP，自动适配三网线路与使用地区，降低延迟。
  • 功能强大：4K 视频秒开，自动解锁流媒体，完美支持 ChatGPT、Gemini 等 AI 大模型。
  • 极简维护：部署简单，后期基本免维护。

2. 搭建步骤（3 步完成）

2.1 注册免费域名

  1. 注册 1-2 个免费域名备用。
  2. 推荐后缀：优先选择 ccwu.cc（其他域名可能无法托管 Cloudflare），或者 cc.cd。
  3. 也可使用 GitHub 账号授权解除限制。
  4. 关键操作：注册完成后，修改域名的 DNS 服务器。

2.2 注册 Cloudflare 并托管部署

  1. 托管域名：注册 Cloudflare 并将域名托管上去。托管好之后会是下面的状态：

  1. 创建 Pages：左侧列表找到 Workers 和 Pages → 创建新 Pages：

  1. 选择最下面的 Pages：

  1. 在里面上传项目文件包。项目由 cmliu 大神开源，最新版本为 2.1。下载完成后，把文件包上传到 Pages 里，按步骤继续操作。

  1. 创建 KV 空间：左侧列表 存储和数据库 → Workers KV → 创建一个新的 KV 空间（名称随意）。

  1. 设置变量与密钥：进入 Pages 设置 → 变量和密钥 → 添加变量：
    • 变量名：ADMIN
    • 值：自定义的密码（用于登录面板）
  2. 设置绑定：在设置中点击 绑定 → 添加 → 下拉找到 KV 命名空间：
    • 变量名称：必须是大写 KV
    • 命名空间：选择刚刚创建好的空间

  1. 绑定自定义域：回到 Pages 项目 → 自定义域 → 填入申请的域名 → 按步骤操作，等待 Cloudflare 自动部署 SSL。

等待 SSL 自动部署完成：

2.3 访问面板并使用

  1. 打开面板：在申请的域名后加 /admin。
    • 示例：https://kejicode.ccwu.cc/admin
  2. 登录：输入之前设置的 ADMIN 密码。

  1. 下载客户端：若无 V2ray 或 Clash，需下载客户端：
    • V2rayN 下载
    • Clash Verge 下载

3. 常见问题与排错

  • 报错：「请设置 变量名称 为 ADMIN 的环境变量」
    • 原因：变量名大小写错误。
    • 解决：变量名必须为大写 ADMIN。
  • 网速慢/卡顿怎么办？
    • 解决：试试换个延迟低的节点。
  • 必须添加自定义域吗？
    • 说明：不添加也可以用，但添加域名更稳定且方便记忆。

4. 相关资源

  • 开源项目作者：cmliu（项目版本 2.1）
  • 推荐免费域名：ccwu.cc / cc.cd
  • 推荐客户端：V2rayN / Clash Verge
